어느 카드를 고를까

  • 평일 출퇴근 — 서울양양고속도로로 올라타는 진입 대기는 주요 나들목 병목, 강동·잠실·판교·구리·남양주 방면별 본선은 출퇴근 시간대 병목.
  • 주말 쇼핑·나들이 — 스타필드는 스타필드 하남 (주차 혼잡도 포함), 미사경정공원·한강공원은 미사·조정경기장.
  • 검단산·북한강·양평 방면 드라이브 — 국도 45호선은 팔당대교~조안.
  • 고속도로 장거리 — 강일IC~덕소IC 본선과 현대아울렛 다산은 서울양양고속·아울렛·현대아울렛 방면.

페이지 안에서 구간별 카메라 버튼으로 지점을 고릅니다. LIVE 표시는 실시간 스트리밍, 표시가 없으면 약 1분 간격 녹화 갱신 영상입니다.
